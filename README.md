# 🌐 Portfolio Website

A personal portfolio website built with HTML, CSS, and JavaScript, showcasing projects, skills, and contact information. Designed to present a clean and professional online presence.

## 🚀 Live Demo

[View Live](https://alanbiju433.github.io/portfolio-website)

## ✨ Features

- Multi-page layout (Home, About Me, Contact)
- Responsive design with animated background
- Project showcase with screenshot previews
- Contact section with social media links
- Demo video section
- Smooth navigation between pages

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| HTML5 | Page structure |
| CSS3 | Styling & animations |
| JavaScript | Interactivity |
| GitHub Pages | Hosting |

## 📁 Project Structure

```
portfolio-website/
├── index.html              # Home / landing page
├── aboutme.html            # About Me page
├── contact.html            # Contact page
├── demovideo.html          # Demo video page
├── styles.css              # Global styles
├── bg.gif                  # Animated background
└── assets/                 # Screenshots & images
```

## 📌 Pages

- **Home** — Introduction and featured projects
- **About Me** — Background, skills, and experience
- **Contact** — Reach out via social media or email
- **Demo Video** — Project walkthrough video

## ⚙️ Setup

1. Clone the repository
   ```bash
   git clone https://github.com/Alanbiju433/portfolio-website.git
   ```

2. Open `index.html` in your browser — no build step needed.

Or simply visit the [live site](https://alanbiju433.github.io/portfolio-website).
